# harness-kit Projects

## [x] Project P01: Generate the Codex marketplace manifest (v0.4.0)
**Goal/Requirement**: `harness-kit gen` writes the repo-level Codex marketplace
`.agents/plugins/marketplace.json` from the same single source of truth as the Claude
manifest, so a harness repo installs with `codex plugin marketplace add <owner>/<repo>`.
- Generated by default for every consumer (decision: on by default, not opt-in).
- `plugin.meta.toml` `codex = false` marks a plugin Claude-only: it is left out of the
  Codex marketplace and gets no `.codex-plugin/plugin.json` (an existing one is pruned).
- `harness.toml` `[marketplace] display_name` sets the Codex marketplace title
  (default: title-cased `name`).
- Entry defaults: `policy.installation = "AVAILABLE"`, `policy.authentication = "ON_INSTALL"`,
  `category` = the plugin's Codex `interface.category`.
- `gen --check` fails when the file is missing or stale.

**Context**: Codex 0.167.2 already falls back to `.claude-plugin/marketplace.json`, so
installs worked before this change; the native file adds install policy and category and
removes the dependency on that compatibility path.

**Out of Scope**
- Non-local plugin sources (git, npm) in the Codex marketplace.
- Per-plugin overrides of `policy`.
