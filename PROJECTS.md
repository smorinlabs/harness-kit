## [x] Project P02: Codex-only hook files (v0.5.0)
**Goal/Requirement**: a plugin can give Codex its own hook file(s), because Claude Code and
Codex both load `hooks/hooks.json` by default and a hook command that names its harness
cannot be shared.
- `plugin.meta.toml` `codex_hooks`: a `./`-prefixed path, or a non-empty list of them, inside
  the plugin root.
- When set, `.codex-plugin/plugin.json` gets `"hooks": <value>`. Codex then uses those files
  instead of `hooks/hooks.json` (learn.chatgpt.com/docs/hooks, "Plugin-bundled hooks").
- The Claude manifest is unchanged.
- First consumer: `smorinlabs/bitrot-sanitation-skill` (its design D-1).

**Out of Scope**
- Inline hook objects in the manifest.
- Checking that the named files exist.

- [x] [P02-TS02] A path or a list renders into the Codex manifest only
- [x] [P02-TS03] A path without `./`, with `..`, an empty list, or a non-string raises
- [x] [P02-T01] `load_meta` and `render_codex_plugin` in `manifests.py`; README updated

## [x] Project P01: Generate the Codex marketplace manifest (v0.4.0)
**Goal/Requirement**: `harness-kit gen` writes the repo-level Codex marketplace
`.agents/plugins/marketplace.json` from the same single source of truth as the Claude
manifest, so a harness repo installs with `codex plugin marketplace add <owner>/<repo>`.
- Generated by default for every consumer (decision: on by default, not opt-in).
- `plugin.meta.toml` `codex = false` marks a plugin Claude-only: it is left out of the
  Codex marketplace and gets no `.codex-plugin/plugin.json` (an existing one is pruned).
- `harness.toml` `[marketplace] display_name` sets the Codex marketplace title
  (default: title-cased `name`).
- Entry defaults: `policy.installation = "AVAILABLE"`, `policy.authentication = "ON_INSTALL"`,
  `category` = the plugin's Codex `interface.category`.
- `gen --check` fails when the file is missing or stale.

**Context**: Codex 0.167.2 already falls back to `.claude-plugin/marketplace.json`, so
installs worked before this change; the native file adds install policy and category and
removes the dependency on that compatibility path.

**Out of Scope**
- Non-local plugin sources (git, npm) in the Codex marketplace.
- Per-plugin overrides of `policy`.

### Tests & Tasks
- [x] [P01-TS01] Fixture with 2 Codex-capable plugins and 1 Claude-only plugin lists exactly the 2
- [x] [P01-TS02] `gen --check` exits 1 when the file is missing or stale, 0 after `gen`
- [x] [P01-TS03] Output matches a structural pin of the Codex marketplace schema
- [x] [P01-T01] `render_codex_marketplace` in `manifests.py`; docstring and README updated
- [x] [P01-T02] Release v0.4.0; `smorinlabs-skills` pins `tag = "v0.4.0"`
